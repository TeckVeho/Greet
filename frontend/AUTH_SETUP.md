# 認証機能とユーザー管理機能の実装について

## 実装した機能

### 1. ログイン画面
- パス: `/login`
- メールアドレスとパスワードでのログイン機能
- テストアカウント情報を画面に表示

#### テストアカウント
- **管理者**: admin@example.com / admin123
- **一般ユーザー**: user@example.com / user123

### 2. ユーザー管理画面
- パス: `/admin/users`
- 管理者のみアクセス可能
- ユーザーの一覧表示、検索、追加、編集、削除機能

### 3. 認証コンテキスト
- グローバルな認証状態管理
- ローカルストレージを使用してセッションを保持
- すべてのページで認証チェックを実施

## 使い方

1. 開発サーバーを起動
   ```bash
   npm run dev
   ```

2. ブラウザで http://localhost:3000 にアクセス

3. ログインページが表示されるので、テストアカウントでログイン

4. 管理者アカウントでログインすると、サイドバーに「ユーザー管理」メニューが表示される

5. ログアウトする場合は、サイドバー下部の「ログアウト」ボタンをクリック

## 注意事項

### 本番環境での使用について

現在の実装は**開発・デモ用**です。本番環境で使用する場合は、以下の対応が必要です：

1. **認証の強化**
   - パスワードのハッシュ化（bcrypt等）
   - JWTトークンまたはセッション管理
   - Next-Authやauth.jsなどの認証ライブラリの使用を推奨

2. **バックエンドAPI**
   - 現在はモックデータを使用
   - 実際のデータベースとAPIエンドポイントの実装が必要

3. **セキュリティ対策**
   - CSRF対策
   - セキュアなCookie設定
   - HTTPS通信の必須化
   - レート制限の実装

4. **権限管理**
   - より詳細なロールベースアクセスコントロール（RBAC）
   - ページレベル・機能レベルでの権限チェック
