# 01 システム概要

## 1. プロジェクト概要

| 項目 | 内容 |
|------|------|
| システム名 | **Greet（グリート）** |
| キャッチコピー | 接待を、戦略に。 |
| 目的 | 法人向け接待飲食店情報の社内共有・管理プラットフォーム |
| 対象ユーザー | 接待業務を行う法人社員・管理者 |

### 背景と目的

接待の場選びは、ビジネスの成否を左右する重要な業務である。しかし、多くの企業では接待に使える飲食店情報が属人化しており、担当者が変わるたびに情報が失われている。Greet は、社内で接待飲食店の情報・レビュー・評価を共有・蓄積し、接待準備の効率化と品質向上を実現するシステムである。

## 7. 非機能要件

| 項目 | 要件 |
|------|------|
| 可用性 | 平日稼働時間帯（9:00〜22:00）の稼働率 99% 以上 |
| レスポンス | API レスポンスタイム 500ms 以内（一般操作） |
| セキュリティ | JWT 認証・パスワードハッシュ（bcrypt）・HTTPS 必須 |
| スケーラビリティ | 初期: 単一 EC2 インスタンス、必要に応じてスケールアップ |
| データ保護 | RDS 自動バックアップ（7日間保持） |
